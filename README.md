# 🏠 گھر کا حساب

آمدن، اخراجات اور بچت — ایک نظر میں۔
یہ ایک نجی (Private) موبائل ایپ (PWA) ہے، خاص طور پر آپ اور آپ کی اہلیہ کے مشترکہ استعمال کے لیے بنائی گئی ہے۔ دونوں فون آپس میں خودکار Sync ہوں گے۔

---

## ✨ خصوصیات

- ماہانہ آمدن، آج کا خرچ، مجموعی خرچ، بچت اور باقی رقم — ایک نظر میں
- مقررہ اخراجاتی مدات (گوشت، سبزیاں، پھل، بل، سودا سلف، جیب خرچ، غیر متوقع، جمعرات کی دعوت) بمع ذیلی مدات
- بچت کو الگ Financial Goal کے طور پر ٹریک کرنا
- دو فونز کے درمیان Real-time Cloud Sync (Supabase)
- ہر اندراج کے ساتھ "کس نے درج کیا" (Activity History)
- ہر مہینے کا ریکارڈ الگ الگ محفوظ، پچھلے مہینوں کو دیکھنے کی سہولت
- فی مد ماہانہ بجٹ کی حد اور تنبیہی پیغام
- خرچ کا تجزیہ (سب سے زیادہ خرچ ہونے والی مدات، چارٹ)
- Home Screen پر انسٹال کرنے کے قابل (PWA)، آف لائن بھی کھلتی ہے

---

## 🚀 سیٹ اپ — قدم بہ قدم

### 1) Supabase پراجیکٹ بنائیں (مفت)

1. [supabase.com](https://supabase.com) پر جا کر مفت اکاؤنٹ بنائیں۔
2. **New Project** بنائیں (کوئی بھی نام، مثلاً `ghar-ka-hisab`)۔
3. پراجیکٹ بننے کے بعد بائیں مینو میں **SQL Editor** کھولیں۔
4. اس ریپو کی فائل `supabase_schema.sql` کا پورا مواد کاپی کر کے پیسٹ کریں اور **Run** دبائیں۔
5. بائیں مینو میں **Project Settings → API** پر جائیں۔ وہاں سے دو چیزیں نوٹ کر لیں:
   - **Project URL** (مثلاً `https://xxxxx.supabase.co`)
   - **anon public key** (ایک لمبی سی Key)

یہ دونوں چیزیں آپ کو ایپ کے پہلی بار چلانے پر درکار ہوں گی۔ چونکہ ایپ کی رازداری کا انحصار "خاندانی کوڈ" پر ہے، اس لیے یہ Project URL اور anon key کسی کے ساتھ شیئر نہ کریں۔

### 2) ایپ کو GitHub Pages پر ڈالیں (مفت ہوسٹنگ)

```bash
# اپنے کمپیوٹر پر:
git init
git add .
git commit -m "گھر کا حساب — پہلا ورژن"
git branch -M main
git remote add origin https://github.com/<آپ-کا-یوزرنیم>/ghar-ka-hisab.git
git push -u origin main
```

پھر GitHub ریپو میں: **Settings → Pages → Branch: main → / (root) → Save**
چند منٹ بعد ایپ اس پتے پر لائیو ہوگی:
`https://<آپ-کا-یوزرنیم>.github.io/ghar-ka-hisab/`

> ⚠️ **اہم**: چونکہ آپ نے کہا یہ صرف نجی استعمال کے لیے ہے، بہتر ہے کہ GitHub پر **Private Repository** بنائیں۔ نجی ریپو پر بھی GitHub Pages مفت میں کام کرتا ہے اگر آپ کا GitHub اکاؤنٹ Pro ہو؛ اگر مفت اکاؤنٹ ہے تو Pages صرف Public ریپو پر بنے گی — ایسی صورت میں کوڈ خود تو نظر آ جائے گا (جس میں کوئی نجی ڈیٹا نہیں، صرف ایپ کا ڈھانچہ ہے) لیکن آپ کا اصل خرچ کا ڈیٹا Supabase میں محفوظ رہتا ہے، ریپو میں نہیں۔ اگر آپ چاہیں تو متبادل کے طور پر **Netlify** یا **Vercel** پر بھی یہ فولڈر مفت اور نجی طور پر ڈیپلائے کیا جا سکتا ہے۔

### 3) اپنے فون پر ایپ کھولیں

1. لنک اپنے موبائل براؤزر میں کھولیں۔
2. پہلی اسکرین پر:
   - اپنا نام منتخب کریں (مناظر / اہلیہ / دیگر)
   - Supabase Project URL اور anon key پیسٹ کریں
   - **خاندانی کوڈ خالی چھوڑ دیں** (پہلی بار — خودکار بن جائے گا)
3. "شروع کریں" دبائیں۔
4. سیٹنگز میں جا کر **خاندانی کوڈ** کاپی کریں۔

### 4) اہلیہ کے فون پر

1. وہی لنک ان کے فون پر کھولیں۔
2. اسی Project URL اور anon key کے ساتھ، لیکن اس بار **خاندانی کوڈ کے خانے میں وہی کوڈ پیسٹ کریں** جو آپ نے کاپی کیا تھا۔
3. نام میں "اہلیہ" منتخب کریں۔

بس — اب دونوں فون ایک ہی حساب دیکھیں گے اور فوری طور پر Sync ہوں گے۔

### 5) Home Screen پر انسٹال کریں

- **Android (Chrome)**: تین نقطوں والے مینو میں "Add to Home screen" یا "Install app" دبائیں۔
- **iPhone (Safari)**: نیچے Share آئیکن → "Add to Home Screen"۔

## 📁 فائلوں کی فہرست

| فائل | مقصد |
|---|---|
| `index.html` | ایپ کا مرکزی ڈھانچہ |
| `style.css` | ڈیزائن اور تھیم |
| `app.js` | ایپ کی مکمل منطق (Logic) |
| `manifest.json` | PWA کی تفصیلات (Home Screen پر انسٹال کے لیے) |
| `sw.js` | آف لائن کیشنگ (صرف ایپ کا خول، ڈیٹا نہیں) |
| `supabase_schema.sql` | ڈیٹا بیس بنانے کی اسکرپٹ |
| `icons/` | ایپ آئیکنز |

## 🔒 رازداری کے متعلق نوٹ

اس ایپ کی رازداری کا انحصار دو خفیہ چیزوں پر ہے: **Supabase anon key** اور **خاندانی کوڈ**۔ جس کے پاس یہ دونوں ہوں، وہی ڈیٹا تک رسائی رکھ سکتا ہے۔ یہ سادہ ذاتی استعمال کے لیے کافی ہے، لیکن یہ انٹرپرائز درجے کی سیکیورٹی (باقاعدہ Login/Password) نہیں۔ اگر مستقبل میں آپ ای میل/پاس ورڈ والا مکمل Login سسٹم چاہیں (زیادہ سخت حفاظت کے لیے)، وہ اگلے مرحلے میں شامل کیا جا سکتا ہے۔
